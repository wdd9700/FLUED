# FLUED v3.4 硬盘迁移后实验总报告

日期：2026-07-15

## 1. 报告地位

本文汇总硬盘迁移恢复后完成的全部 v3.4 修正版实验，是当前实验结论的第一入口。
7 月 10--13 日文档继续保留历史价值，但凡涉及 byte lookup、memory、decoder、边界执行和
位置/小 AR 默认值时，以本文和 `FLUED_V3_4_RERUN_MATRIX_20260714_CN.md` 为准。

本轮没有训练 300M 最终模型。目标是在约 38M FLUED + 4.9M 临时 backbone 上，先把组件
贡献、训练动力学和真实计算预算分开。

## 3. 结论总表

| 问题 | 实验结论 | 当前决策 |
| --- | --- | --- |
| 固定 0.9 阈值能否训练 | B9 10K 同分母切分比 1.138，相关性 0.816，无溢出 | 保留固定阈值和正边界 margin，不默认启用对偶变量 |
| readout mask 还是 chunk mask | readout mask 的补全困惑度 49.74；chunk mask 53.70 | 保留 readout 级补全 |
| 位置编码是否必要 | 关闭位置后可学习硬边界归零 | RoPE/ALiBi 必须保留 |
| 小 AR 是否必要 | 有位置时重建 18.58% -> 21.51%；无位置时无效 | 与位置编码联合保留 |
| 编码率估计器 | L2 任务前沿更好，但有容量溢出和边界漂移 | 对角估计器作为稳定基线；L2 继续研究 |
| 结构化 lookup 是否有效 | 同预算下普通 lookup 为 26.06%/46.62，结构化为 21.50%/48.54 | 当前默认改为普通 byte lookup |
| 软发声能否省计算 | 软发声实际 latent 约为硬发声两倍，质量无收益 | 只保留硬前向、连续直通反传 |
| memory 是否改善前沿 | 同预算 0.13 latent/byte 时，no-memory 19.69%/43.85，memory 18.28%/44.21 | memory 降级为可选分支 |
| 共享反向 decoder 是否成立 | 同预算 0.20 时，共享对角 21.00%/43.37，独立 decoder 40.92%/30.83 | 当前最大 blocker，禁止直接扩到 300M |

表中斜线表示“重建准确率 / masked-byte 困惑度”。

## 4. 边界闭环与指标修正

早期报告的 10K 切分比 0.726 使用了错误分母：实际切分除以全部有效 byte，目标切分除以
排除了 UTF-8 continuation 和首位置的可切边界。修正后必须比较：

```text
requested_eligible_hard_cut_fraction
/
boundary_rate_target_cut_fraction
```

B9 从头 10K 的修正结果：

| 指标 | 数值 |
| --- | ---: |
| 实际/目标切分比 | 1.138 |
| 编码率相关性 | 0.816 |
| continuation 均值 | -0.939 |
| 标点均值 | 0.353 |
| 普通边界均值 | -0.077 |
| 补全困惑度 | 47.590 |
| 实际 latent/byte | 0.344 |
| 容量溢出/截断 | 0 / 0 |

训练期对偶分支也通过，但最终对偶变量回到 0，因此没有证据支持把它加入默认训练路径。

## 5. 5K 结构消融

### 5.1 核心路径

| 组 | decoder / mask | 重建 | 补全 | 困惑度 | latent/byte |
| --- | --- | ---: | ---: | ---: | ---: |
| C1 | 共享反向 / readout | 21.51% | 11.08% | 49.74 | 0.326 |
| C2 | 独立 / readout | 28.61% | 12.64% | 39.87 | 0.690 |
| C3 | 共享反向 / chunk | 27.56% | 10.87% | 53.70 | 0.224 |

阈值扫描后，在约 0.40--0.45 latent/byte 下，C2 困惑度 40.42，C1 为 48.62。独立 decoder
的短程优势不是简单通过多发 latent 获得。chunk mask 虽提高局部重建，却显著伤害严格补全。

### 5.2 位置编码和小 AR

| 位置 | 小 AR | 重建 | 困惑度 | latent/byte | 可学习边界 |
| --- | --- | ---: | ---: | ---: | --- |
| 开 | 开 | 21.51% | 49.74 | 0.326 | 正常 |
| 开 | 关 | 18.58% | 50.59 | 0.220 | 正常 |
| 关 | 开 | 11.72% | 50.19 | 0.081 | 归零 |
| 关 | 关 | 11.71% | 49.91 | 0.076 | 归零 |

小 AR 位于切分之后，不能替代 Segmentor 所需的位置。二者是协同关系，不是互斥选择。

### 5.3 编码率

| 估计器 | 重建 | 困惑度 | latent/byte | 问题 |
| --- | ---: | ---: | ---: | --- |
| 对角 | 21.51% | 49.74 | 0.326 | 稳定但任务信号偏弱 |
| 精确行列式 | 29.72% | 49.31 | 0.678 | 先欠切、后过冲 |
| L2 | 25.29% | 48.70 | 0.354 | 容量溢出，普通边界均值 0.202 |

L2 不是效果差，而是把局部高能量过度解释为切分价值。后续需要校准边际任务收益和真实
计算成本，而不是继续提高其损失权重。

### 5.4 lookup 与发声

| lookup | 发声 | 重建 | 困惑度 | 实际 latent/byte |
| --- | --- | ---: | ---: | ---: |
| 16x16 结构化 | 硬 | 21.51% | 49.74 | 0.326 |
| 普通 byte | 硬 | 26.96% | 47.47 | 0.385 |
| 16x16 结构化 | 软 | 24.75% | 51.16 | 0.759 |
| 普通 byte | 软 | 25.14% | 47.55 | 0.787 |

当前 16x16 网格为 byte ID 注入了任意二维邻接关系，数据没有支持该先验。软门控只改变表示
幅度，不删除 backbone token，因此不能作为计算压缩。

## 6. 20K 长程实验

### 6.1 Memory

| 路径 | 重建 | 补全 | 困惑度 | latent/byte |
| --- | ---: | ---: | ---: | ---: |
| no-memory | 21.00% | 11.28% | 44.30 | 0.204 |
| other-memory | 18.28% | 11.33% | 45.17 | 0.131 |

同预算约 0.13 时，no-memory 同时拥有更高重建和更低困惑度。memory residual ratio 从约
0.078 降至 0.044，说明模型在逐步忽略当前 memory 表示。该结果只否定当前 summarizer +
other-only residual，不否定历史摘要这一研究假设。

### 6.2 Decoder 与 L2

| 路径 | 重建 | 补全 | 困惑度 | latent/byte | 结构状态 |
| --- | ---: | ---: | ---: | ---: | --- |
| 共享反向 + 对角 | 21.00% | 11.28% | 44.30 | 0.204 | continuation 退化到 -0.570 |
| 独立 decoder + 对角 | 48.08% | 13.97% | 30.73 | 0.383 | 无最终溢出；切分比 1.377 |
| 共享反向 + L2 | 48.24% | 13.79% | 39.01 | 0.428 | 仍有溢出；边界先验未过闸 |

同预算约 0.20 latent/byte：

| 路径 | 重建 | 困惑度 |
| --- | ---: | ---: |
| 共享反向 + 对角 | 21.00% | 43.37 |
| 独立 decoder + 对角 | 40.92% | 30.83 |
| 共享反向 + L2 | 29.31% | 39.47 |

训练曲线揭示了 3K 动态边界切换后的恢复能力：

| 步数 | 共享对角重建 | 独立对角重建 | 共享 L2 重建 |
| ---: | ---: | ---: | ---: |
| 3K | 53.6% | 93.0% | 53.6% |
| 6K | 24.4% | 28.7% | 38.8% |
| 12K | 22.9% | 35.7% | 46.4% |
| 18K | 21.7% | 45.6% | 42.6% |
| 20K | 21.2% | 47.7% | 42.9% |

共享对角在课程切换后没有恢复；独立 decoder 持续恢复；L2 为共享路径提供了更强信号，但
曲线不单调且没有解决溢出。这是本轮最关键的新结论。

## 7. 当前决策

### 已验证保留

- 严格 masked-byte 输入；
- readout 级补全；
- RoPE/ALiBi + 小 AR；
- 普通 byte lookup；
- 硬 emit 前向、连续直通反传；
- 固定 0.9 切分阈值和 continuation 硬约束。

### 降级为可选或对照

- 16x16 结构化 lookup；
- 软 emit；
- 当前 other-only memory；
- 精确行列式编码率；
- 训练期对偶变量。

### 尚未闭环

1. 共享非严格反向 decoder 的梯度竞争和动态分段适应能力；
2. L2 编码率的容量溢出与边界语义漂移；
3. 修正版边界的 ROI 人工语义检查；
4. 2048/4096 长度外推；
5. 多种子和 300M 扩模。

目前不存在一个同时满足“保留共享反向 claim、边界过闸、无溢出、任务前沿最优”的正式默认
配置。实证任务赢家是独立 decoder + 对角编码率；claim-preserving 路线仍需修复共享逆路径。

## 9. 下一步验收路径

下一轮先固定预生成 chunk/readout，隔离训练共享逆与独立 decoder。只有共享逆在固定输入下仍
显著落后，才归因于逆映射本身；若固定输入下差距消失，则问题来自 Segmentor、emit、编码器
和 decoder 的联合非平稳优化。在完成该归因前，不启动 300M 正式扩模。

## 10. 后续最小归因更新

上述归因已经完成第一轮，详见
[`FLUED_V3_4_MINIMAL_ATTRIBUTION_RESULTS_20260715_CN.md`](FLUED_V3_4_MINIMAL_ATTRIBUTION_RESULTS_20260715_CN.md)：

- 共享逆在冻结 readout 上训练 1K 后从 21.38% 提升到 56.28%，没有表现出函数形态完全失效；
- memory 的样本内 chunk 打乱只使补全困惑度增加 0.016，当前内容对应关系几乎未被利用；
- 课程在 3K 时给 Segmentor 的主任务梯度为 0，6K 完全接管后梯度 L2 突增至 23--56，确认
  存在明显的信用分配冲击。

因此首要问题从“删除共享逆或直接扩模”修正为“解耦共享逆训练，并平滑开放边界主任务梯度”。
