# FLUED v3.4 20K 边界策略与课程训练分析

日期：2026-07-11

## 1. 问题

5K 消融无法区分两种情况：

```text
方案已经到达上限
vs
方案早期优化更慢，但长期上限更高
```

因此本轮对三种固定边界策略从头训练 20K，并增加用户提出的课程训练：先用 uniform boundary 学会 byte reconstruction，再切换到 L2 marginal rate 优化边界。

## 2. 公平口径

| 项目 | 值 |
| --- | --- |
| FLUED | 37,264,917 参数 |
| 临时补全主干 | 4,783,232 参数 |
| 总参数 | 42,048,149 |
| 数据 | 22.14GB corpus_v3 |
| 序列长度 | 512 bytes |
| batch | 8 |
| seed | 42 |
| 训练步数 | 每组 20,000 |
| 学习率 | 2e-4，200-step warmup，按 20K 余弦衰减 |
| mask 比例 | 5% |
| 日志 | 每 20 步；无 token 截断 |

所有组都从头训练。没有续接旧 5K checkpoint，因为旧 scheduler 已按 5K 衰减完，直接续训会系统性压低慢热方案。

## 3. 最终评估

| 方案 | 重建准确率 | masked completion | 实际 latent/byte | 约合 bytes/latent | 定位 |
| --- | ---: | ---: | ---: | ---: | --- |
| 精确边际编码率 | 77.84% | 13.37% | 0.4928 | 2.03 | 稳定但慢，最终低于 L2 |
| L2 边际编码率 | 79.85% | 11.98% | **0.4431** | **2.26** | 压缩最强，但补全最弱 |
| 均匀边界 | **99.69%** | 14.57% | 0.5905 | 1.69 | 重建上限，压缩较弱 |
| **uniform 3K -> L2** | **88.85%** | **14.74%** | **0.5225** | **1.91** | 当前最佳综合折中 |

课程训练结果非常接近预先提出的目标形状：

```text
预期：约 85% reconstruction / 16% completion / 0.55 latent per byte
实测：88.85% / 14.74% / 0.5225
```

补全没有达到 16%，但课程训练取得四组最高补全准确率，同时比 uniform 减少约 11.5% 的实际 backbone latent。

## 4. 长程曲线

### 4.1 重建准确率快照

| 方案 | 5K | 10K | 15K | 20K 训练点 | 最终评估 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 精确边际编码率 | 56.23% | 72.56% | 77.71% | 77.10% | 77.84% |
| L2 边际编码率 | 66.85% | 79.30% | 92.26% | 86.62% | 79.85% |
| 均匀边界 | 99.63% | 98.75% | 99.63% | 99.88% | 99.69% |
| uniform -> L2 | 80.98% | 87.38% | 91.92% | 89.79% | 88.85% |

单个训练点波动较大，最终比较以固定 eval 为准。曲线仍明确证明 exact 和 L2 在 5K 后继续学习，原 5K 结果不能代表长期上限。

### 4.2 curriculum 切换行为

切换前 2.5K-3K：

```text
平均重建 97.15%
平均实际 latent/byte 0.924
```

3K 硬切换后：

```text
重建瞬间从约 99% 降至 41%-59%
实际 latent/byte 一度升至约 1.05
```

按 200-step 滚动均值计算：

| 恢复阈值 | 切换后所需步数 |
| --- | ---: |
| 重建 75% | 600 |
| 重建 80% | 960 |
| 重建 85% | 9,000 |
| 重建 90% | 20K 内未稳定达到 |

这说明课程训练有效，但当前的硬切换不是“无痛切换”。边界重排会暂时破坏 readout、decoder 和 backbone 已建立的对齐。

### 4.3 curriculum 后程趋势

| 区间 | 平均重建 | 平均补全 | 平均实际 latent/byte |
| --- | ---: | ---: | ---: |
| 3K-3.5K | 63.38% | 11.64% | 0.945 |
| 3.5K-5K | 79.04% | 13.15% | 0.812 |
| 5K-10K | 67.25% | 11.64% | 0.483 |
| 10K-15K | 79.54% | 12.68% | 0.487 |
| 15K-20K | **87.98%** | **14.06%** | **0.550** |

5K-10K 的再次下降表明 emit/边界/readout 仍在共同重排；15K 后才进入更好的联合解。因此课程训练的收益不是简单继承 uniform 权重，而是给 L2 提供了更好的表示起点。

## 5. 结论

1. **“L2 只是慢热”只对了一半。** L2 的长期重建高于 exact，压缩也最强，但补全任务明显较弱，并非单纯多训练就能全面胜出。
2. **uniform 是可靠的 codec 预训练器。** 它快速建立 byte-readout-decoder 对齐，并给临时 backbone 提供较平滑的早期输入。
3. **uniform -> L2 是当前最佳主线候选。** 它获得最高补全、明显高于固定 L2/exact 的重建，并保留优于 uniform 的压缩。
4. **硬切换代价过大。** 下一版应测试 1K-2K 步的软过渡，而不是在 step 3000 瞬间完全替换边界。
5. **仍不能声称语义切分已解决。** 当前结果证明优化和 Pareto 改善，尚需 ROI、边界扰动稳定性、长文本和多种子验证。

当前建议训练流程：

```text
阶段 A：uniform boundary，先建立可逆翻译和主干补全接口
阶段 B：uniform/L2 软混合，逐步释放边界自由度
阶段 C：纯 L2，自适应优化切分和实际 latent 数量
```

原始日志、汇总和交互曲线见 [`results/v3.4/20k_rate_comparison/`](../../../results/v3.4/20k_rate_comparison/README.md)。
